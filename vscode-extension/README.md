# Codebot Chat for VS Code

该扩展把 Codebot 的现有聊天后端带入 VS Code 侧栏。界面采用固定底部输入区，消息区独立滚动；模式、目标和模型直接显示在输入框下方、“终端选区”左侧。

支持：

- Editor / Build / Plan / Agent 模式；Editor 默认面向当前工作区做精确源码修改；
- Codebot、Hermes、Obsidian、Hermes + Obsidian 目标；
- Codebot 当前模型列表；
- `/` 命令、`@` Skill 与 `#` 知识库快速插入；知识库不会常驻显示为复选框；
- 当前 VS Code 工作区作为项目目录；
- 在编辑器中选中代码并停止调整选区后，会就地出现“加入 Codebot 对话”；编辑器右键菜单也保留同一命令；
- 终端右键或输入框下方“终端选区”把选中输出加入对话。VS Code 稳定扩展 API 不提供终端选区变化事件，因此这里保留显式入口；
- Codebot 侧栏提供原生“拖放文件到对话”区域；从资源管理器直接拖到该区域，无需按 Shift，放下后文件会加入聊天输入上下文；
- VS Code 会屏蔽资源管理器到 Webview 输入框的拖放事件，而且修饰键不可由扩展自定义，因此不再保留不可达的输入框拖拽实现；
- 也可点击输入框下方“文件”，或在资源管理器右键选择“Codebot: 将文件加入对话”；
- 历史对话选择、任务续接、NDJSON 流式回复和对话持久化；扩展重新加载后会从后端恢复真实运行态，防止同一句重复排队；
- 工具调用、会话状态、空闲用时和模型/API 错误会即时显示，不再以空白气泡伪装为完成；
- 每条消息支持复制，顶部支持复制整个对话；用户消息支持撤销，该轮及之后的对话会删除，关联工作区会通过 Codebot 独立 Git 快照恢复到该轮修改前；
- 发送中按钮会切换为“停止”；`Enter` 发送，`Ctrl+Enter` 换行。

## 开发安装

1. 先启动 Codebot 桌面版。
2. 在本目录执行 `npm install`，再执行 `npm run package`。
3. 在 VS Code 中运行“Extensions: Install from VSIX...”，选择生成的 `.vsix`。
4. 打开左侧活动栏中的 Codebot 原生机器人图标。

扩展会依次尝试 `http://127.0.0.1:18080`（开发版）和 `http://127.0.0.1:15682`（正式版）。如使用其他地址，请设置 `codebot.backendUrl`。

## 安全边界

Webview 不能直接访问文件系统或启动进程；所有网络请求都由 VS Code 扩展宿主发往用户配置或本机 Codebot 地址。项目修改仍由 Codebot/OpenCode/Hermes 在用户当前工作区权限范围内完成。
